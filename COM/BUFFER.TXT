THE PROGRAM BUFFER.COM IS A DOS COMMAND PROGRAM.
THE PROGRAM CAN BE RUN BY TYPING 'BUFFER' WHILE IN DOS,
HOWEVER IT SHOULD ONLY BE RUN ONE TIME SINCE IT WILL ATTACH
ITSELF TO DOS AND WILL THEREFORE STAY IN MEMORY.
THE PROGRAM WILL EXTEND THE SIZE OF THE KEYBOARD BUFFER FROM
15 TO 159 CHARACTERS.
THE BUFFER WILL REMAIN AT 159 CHARACTERS UNTIL YOU REBOOT THE
COMPUTER.
