THE PROGRAM CALLED UNPROT.BIN IS A BINARY PROGRAM.
IT CAN BE LOADED IN BASIC BY TYPING 'BLOAD"UNPROT.BIN",1124'
THE PROGRAM WAS DESIGNED TO UNPROTECT A BASIC PROGRAM WHICH
WAS SAVED WITH THE ,P EXTENSION.
 TO USE:
LOAD BASIC
LOAD PROTECTED PROGRAM
LOAD UNPROT.BIN
THE PROGRAM IN MEMORY IS NOW UNPROTECTED AND CAN BE 
LISTED AND MODIFIED. SAVE THE PROGRAM IF YOU WANT THE
COPY ON THE DISK TO BE UNPROTECTED AS WELL.
